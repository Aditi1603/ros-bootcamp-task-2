# Submission Format

1. **Fork** this repository:
   https://github.com/Rudraksh919/ros-bootcamp-task-2

2. Create a folder named in forked repository:

   ```text
   rollno_firstname/
   ```

3. Inside the folder, submit:

   * `/src` — Your complete source code
   * `README.md` — Documentation
   * `Video Demonstration` — Short demonstration video

4. In `README.md`, briefly explain:

   * How you built the solution
   * SLAM & exploration approach
   * Map merging approach
   * How to run it

5. Add a **short demonstration video** showing the complete system working.

6. Submit by pushing everything to your fork.

7. Create a **Pull Request (PR)** to merge it into the `main` branch and inform me in the group.

8. **Important:** Everyone must follow the above submission format. If your submission lacks any required item or you try to push build files, you will be removed from the group without any warning.
